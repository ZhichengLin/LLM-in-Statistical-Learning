# Figures — Study 1 and Study 2

R notebooks generating the code-produced paper figures (Main Figs. 3–6 and SI
Fig. S1), with outputs in `figure/` (PDF, PNG, and SVG). The same directory also
contains byte-for-byte copies of the current manually authored Main Figs. 1 and
2. The canonical notebooks use publication-size Helvetica typography, explicit
physical stroke widths, and 300-dpi PNG export.

## Data (`data/`)

| File | Description |
|------|-------------|
| `Study_1_Objective_Data.xlsx` | LLM objective accuracy (Study 1) |
| `Study_1_Subjective_Data.xlsx` | Human subjective ratings (Study 1) |
| `Correction_Data.csv` | Early/late correction data for the Study 2 correction figure |
| `Correction_Timing_Contrasts.csv` | Model-derived early/late contrasts and p-values used in Figure 5 |

Main Figs. 5–6 and Fig. S1 read the canonical Study 2 full-sample workbook
directly from
`../Study_2_FollowUp_Results/MAR/data/Study_2_Full_Data.xlsx`. Figs. 5–6 also
read the deidentified cohort in `../Study_2_LongTerm_Results/data/cohort.csv`
and require the READY binding produced by that module. No private inputs or
separately maintained plotting workbook are required. The earlier deposited
pseudonyms are deterministically aligned with the public long-term keys
inside each notebook; the original source workbook remains unchanged.

## Notebooks

| File | Figure |
|------|--------|
| `Figure_Study1_1.Rmd` | Main Fig. 3: Study 1 LLM accuracy and run-to-run variability |
| `Figure_Study1_2.Rmd` | Main Fig. 4: Study 1 quality ratings by model and rater group |
| `Figure_Study2_1.Rmd` | Main Fig. 5: Study 2 accuracy trajectories and correction timing |
| `Figure_Study2_2.Rmd` | Main Fig. 6: confidence, willingness, and perceived usefulness |
| `Figure_S01_AI_Related_Measures.Rmd` | Fig. S1: AI attitudes, literacy, and self-efficacy over time |
| `reproduce_completer_tests.R` | Retained published Figure 6 completer mixed models; regenerates the six aggregate P values and model sample counts |
| `plot_util_test.R` | Helper `data_preprocessing()`: wide→long reshape, within-subject normalisation, Cousineau–Morey 95% CIs |

Each notebook writes its figure to `figure/` in PDF, PNG, and SVG. Run the
ordered repository workflow (`Rscript reproduce.R all` from the repository
root) so that analyses, the original completer tests, and the long-term READY binding precede the figures.

Figs. 5–6 retain the approved manuscript typography and geometry: Helvetica
7 pt, the existing physical stroke widths, colours, and shapes. Their PDF
export requires macOS Quartz to preserve fractional glyph advances; SVG and
300-dpi PNG use their existing devices. These are documented exceptions to
the default DataPlot template, preserving the existing manuscript figures.

For individual renders, work from `Figures/`. `FIGURE5_REPO_ROOT` /
`FIGURE6_REPO_ROOT` select another public repository root, and
`FIGURE5_READY_RUN` / `FIGURE6_READY_RUN` select an alternative verified
long-term run. `FIGURE5_OUTPUT_DIR` / `FIGURE6_OUTPUT_DIR` and
`FIGURE5_DATA_OUTPUT_DIR` / `FIGURE6_DATA_OUTPUT_DIR` redirect generated
artwork and aggregate CSVs. Figs. 5–6 fit no inferential models.

The immutable earlier workbook and plotting helper are verified against
`publicfigure_input_manifest.json`. Regenerated correction CSVs are checked
for their schema, ranges, uniqueness, scaling, and contrast P-value
relationships. Fig. 6 checks displayed full-sample P values against the
regenerated H2 workbook by value, without pinning unstable XLSX container
bytes. Its completer-only P values are regenerated by `reproduce_completer_tests.R`
under the original root `renv.lock`, using the published model formula,
covariate recoding, factor levels, and `emmeans` defaults. The script exports
only six aggregate contrasts and model sample counts to
`data/figure6_completer_tests.csv`. Fig. 6 requires their formatted values to
agree exactly with the preserved three-decimal labels in
`data/fig6_panel_bc_p_values.csv`; rounded labels are not treated as
unrounded P values. No model fit occurs inside the figure notebook.

Keep `data/fig6_panel_bc_p_values.csv` in the checkout: both the test script
and Figure 6 read it before rendering. Figure 6 preserves its twelve verified
display labels and refreshes the provenance descriptions. It is a required
record, rather than a file that can be deleted and regenerated from nothing.

The left panels of Figs. 5–6 connect available-sample means: 175 participants
at Stages 1–3, 84 at one month, and 33 eligible participants with both
follow-ups at 14 months. These connections are not matched within-person
changes. The attrition panels compare only Stages 1–3 for the three samples.
Fig. 5 uses overall 17-item accuracy; the exploratory long-term inferential
analyses weight the three tasks equally. Fig. 6 uses the overall task0
confidence measure. The long-term extension is exploratory and was not
preregistered.

## Static figures

| File | Figure |
|------|--------|
| `figure/Figure_01_Study1_Workflow.pdf` | Main Fig. 1, publication artwork |
| `figure/Figure_01_Study1_Workflow.png` | Main Fig. 1, raster preview |
| `figure/Figure_02_Study2_Participant_Flow_and_Procedure.pdf` | Main Fig. 2, PI-finalized 2026-09-30 artwork; also shows the exploratory long-term wave deposited in `Study_2_LongTerm_Results` |

In Fig. 2, the 46 nonreturners and five reported-assistance exclusions are
counted among the 84 one-month completers, leaving 33 eligible participants
with both follow-ups. Six additional eligible participants had no one-month
data, giving 39 overall. Thus the final box combines two returner groups;
it is not a strict subset of the one-month box. The generated
`../Study_2_LongTerm_Results/results/sample_flow.csv` records both groups.

`Study_1_Objective_Data.xlsx` is synchronized with the objective-analysis copy;
`Study_1_Subjective_Data.xlsx` is value-identical to the subjective-analysis
copy. `Correction_Data.csv` and `Correction_Timing_Contrasts.csv` are regenerated
by `../Study_2_Early_Late_Correction/Comparison.Rmd` before Fig. 5.

Displayed P values are computation-driven: Fig. 3 fits the same Study 1
thinking-mode model as the objective-analysis notebook; Fig. 5 reads the
generated correction contrasts; Fig. 6 reads the generated full-sample H2
contrasts and verifies the regenerated original completer-only H2 aggregate; and Fig. S1 reads
the generated immediate and completer H2 contrasts or fits its documented MAR
models.

The historical analyses use the top-level `renv.lock`; the extended Fig. 5–6
workflow uses the environment recorded with `Study_2_LongTerm_Results`.
Figure-specific dependencies
include `cowplot`, `lemon`, `patchwork`, `ggtext`, `gridExtra`, `gtable`,
`Rmisc`, `lme4`, `lmerTest`, and `emmeans`.
