# Changelog

## 1.1.0 — 2026-10-03

- Add the exploratory 14-month follow-up as a self-contained public module:
  analysis-ready pseudonymous data, eligibility/QC guards, the executed model
  specifications, independent verification, and supplementary Tables S22–S24.
- Add a separate pinned R environment for the extension and current Figure 5/6
  code while preserving the original package lockfile and 175/84 analyses.
- Make current Figures 5–6 reproducible from deposited inputs, retaining the
  approved five-assessment available-sample presentation and macOS Quartz
  typography.
- Include the added post hoc S2-minus-S1 source-label gain contrasts supporting
  SI Table S7 Panel F in the supported workflow.
- Align title, citation metadata, data documentation, and output mapping with
  `Main v2.docx` and `SI v2.docx` (Texts S1–S5; Fig. S1; Tables S1–S24).
- Record the different paired/MAR estimands, post-result exploratory eligibility
  decisions, two retained model diagnostics, and the upstream provenance
  boundary. No manuscript files are included in the repository.
- Suppress excluded returners' long-term outcomes/auxiliary responses and
  deposit elapsed intervals at 0.1-day precision. The latter preserves all
  reported one-decimal summaries and changes no inferential-model input.
